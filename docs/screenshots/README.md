# Скриншоты для README и отчёта

Положите сюда скриншоты после запуска приложения:

| Файл | Что снять |
|------|-----------|
| `login.png` | страница входа (`/static/login.html`) |
| `register.png` | страница регистрации (`/static/register.html`) |
| `index.png` | главная: список заметок, поиск, фильтры, статистика |
| `edit.png` | редактирование заметки (кнопка «Изменить») |
| `swagger.png` | Swagger (`/docs`) со списком эндпоинтов |

Как сделать:

1. Запустить `uvicorn app.main:app --reload`.
2. Зарегистрировать пользователя, создать 2–3 тега и 2–3 заметки.
3. Сделать скриншоты (Win + Shift + S) и сохранить сюда с указанными именами.
4. Вставить их в README.md и ОТЧЕТ.md в разделе «Скриншоты».
